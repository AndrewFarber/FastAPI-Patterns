# Naming guide

| Note | Description |
| --- | --- |
| [[naming]] | The base: modules, functions and factory verbs, variables, booleans, durations, constants, private names, tests. |
| [[naming-domain]] | Builds on [[naming]]: entities, events, errors with the `Error` suffix, protocols and their implementations, use cases and commands. |
| [[naming-infrastructure]] | Builds on [[naming]]: ORM rows, plural tables in the service's schema, constraint naming convention, row-to-entity mapping. |
| [[naming-api]] | Builds on [[naming]]: CRUD and action URLs, route functions, request and response schemas, dependencies, event handlers, the public interface. |

Settings sub-models are named in [[settings-management]].
